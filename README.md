# trmnl-prints

Static image host for Carl's **Now Printing** TRMNL plugin: one grayscale render of the model
currently on the Bambu Lab P1S, committed per print and served through jsDelivr
(`https://cdn.jsdelivr.net/gh/<owner>/trmnl-prints@<commit>/p/<id>.png`).
Generated by `06_TRMNL_Plugins/06_Now_Printing/02_Tools/publish_image.py`. Nothing here is hand-edited.
